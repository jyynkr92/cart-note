# Cart Note Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 마트/사이트별 장보기 목록을 그룹과 실시간 공유하고, 등록한 마트 근처에서 알림을 주는 Expo 앱을 만든다.

**Architecture:** Expo Router 앱이 Supabase(Postgres + RLS + RPC + Realtime)를 직접 호출한다. 서버 상태는 TanStack Query 캐시(AsyncStorage 영속화, 오프라인 mutation 큐)로 관리하고, Realtime 이벤트로 캐시를 갱신한다. 위치 알림은 기기 로컬 지오펜싱(expo-location + TaskManager) + 로컬 알림으로 동작하며, 카카오 장소 검색만 Edge Function을 거친다.

**Tech Stack:** Expo(최신 stable SDK, TypeScript, Expo Router), React Native Reusables + NativeWind, Supabase(supabase-js v2, Supabase CLI, pgTAP), TanStack Query v5 + `@tanstack/query-async-storage-persister`, Zustand(로컬 UI 상태), expo-location, expo-task-manager, expo-notifications, expo-linking, Jest(jest-expo) + React Native Testing Library, Deno test(Edge Function).

**Spec:** `docs/superpowers/specs/2026-11-10-cart-note-design.md`

## Global Constraints

- 플랫폼: iOS/Android 네이티브. 지오펜싱 검증은 EAS 개발 빌드에서만(Expo Go 불가).
- 앱 스킴: `cartnote`. 초대 딥링크: `cartnote://join?code=XXXXXX`.
- 초대 코드: 6자리 숫자 **문자열**(앞자리 0 보존), `families.invite_code` unique.
- 첫 로그인 자동 그룹 이름: `내 장보기`. inbox 목록 이름: `사야할것`.
- 로그인: Supabase 이메일 OTP, 6자리 코드 입력이 기본, 매직링크는 보조.
- 지오펜스 반경 기본값 `300`(m), 등록 한도 `20`곳, 같은 목록 재알림 쿨다운 `3`시간.
- 알림 문구: `"[그룹명] {지점명} 근처예요 · 사야 할 것 {n}개"`. 그룹이 1개면 `[그룹명] ` 생략. 개수를 모르면 `"{지점명} 근처예요"`.
- 빈 그룹 정리 문구: `"비어 있는 '{그룹명}' 그룹을 삭제할까요?"` 버튼 `[삭제] [유지]`.
- 카카오 REST 키는 Edge Function 시크릿(`KAKAO_REST_KEY`)에만 존재. 앱 번들에 넣지 않는다.
- 충돌 정책: last-write-wins. Realtime DELETE 이벤트는 캐시 직접 수정 금지, 쿼리 무효화만.
- 그룹 간 항목 이동 불가(복합 FK로 강제). 그룹 합치기, 구매 기록, 수량 필드, 소셜 로그인, 원격 푸시는 만들지 않는다.
- UI 컴포넌트는 Reusables 우선. 바텀 시트만 `@gorhom/bottom-sheet` 허용.

## Review Focus

1. **공백뿐인 이름**(항목/목록/그룹/표시 이름) → 저장하지 않고 입력 유지. trim 후 빈 문자열이면 무시. → Task 7, 9 테스트에 추가.
2. **초대 코드 입력의 공백/하이픈/앞자리 0** (`" 012 345 "`) → 숫자만 남겨 `"012345"`로 처리, 6자리가 아니면 버튼 비활성. → Task 6 테스트에 추가.
3. **백그라운드 지오펜스 진입 시 세션 없음/만료** → 크래시 없이 개수 없는 알림 대신 **알림 생략**(로그아웃 사용자에게 알림 금지). → Task 14 테스트에 추가.
4. **현재 선택 그룹에서 내가 나가졌거나 그룹이 삭제됨**(다른 기기에서 나가기) → 저장된 선택 그룹이 멤버십에 없으면 첫 번째 그룹으로 폴백, 그룹이 0개면 개인 그룹 생성 흐름. → Task 8 테스트에 추가.
5. **오프라인에서 이동/비우기 후 재연결** → 큐가 순서대로 재실행되고, 앱을 재시작해도 큐가 보존됨. → Task 7 테스트에 추가.
